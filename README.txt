TONY HANNA PORTFOLIO — GITHUB PAGES UPLOAD

1. Create a GitHub repository named YOURUSERNAME.github.io
   Example: if your GitHub username is tonyhanna5505, name it tonyhanna5505.github.io

2. Upload EVERY file and folder from this portfolio folder to the repository root.
   Keep the structure exactly as supplied:
   - index.html
   - projects.html
   - resume.html
   - Tony-Hanna-Resume.pdf
   - assets/
   - projects/

3. In GitHub open Settings > Pages.

4. Under Build and deployment choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   Then click Save.

5. After GitHub deploys the site, open:
   https://YOURUSERNAME.github.io

UPDATING THE SITE
Edit any HTML/CSS file on GitHub and commit the change. GitHub Pages will redeploy automatically.

RESUME
The resume buttons point to Tony-Hanna-Resume.pdf. Keep that exact filename unless you also update the links in resume.html.

PROJECT IMAGES
All current project images are stored locally in assets/images, so the project pages do not depend on Wix image hosting.
